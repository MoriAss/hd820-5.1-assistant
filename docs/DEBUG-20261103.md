# 2026-11-03 深度调试记录

## 背景与边界

用户报告间歇卡顿、托盘窗口打开后闪回后台。排查时实际进程和登录任务仍指向 v3.2.1，桌面快捷方式却指向 v3.2.2；单实例机制使快捷方式唤醒了旧进程。因此不能仅根据桌面快捷方式判断运行版本。

长期累计遥测曾记录输出 padding 耗空、应急丢包和采集/输出线程长间隙。随后旧版连续 600 秒的只读观察没有新增同类计数。两项证据并不矛盾：它们覆盖不同时间范围，且软件计数无法单独证明音箱端连续。

本轮修复明确的软件缺陷，不把所有改动都归因到用户听到的卡顿。

## 修复内容

| 部分 | 发现与修复 | 验证方式 |
| --- | --- | --- |
| 设备下拉框 | 弹出列表没有载入设备项，选中索引可越界；补齐列表与选择同步 | 旧控件复现失败，新控件回归 |
| 按钮与滑块 | WinForms 默认点击与手工点击重复触发；失去鼠标捕获后仍拖拽 | 重放框架点击路径、捕获丢失测试 |
| 绘制与电平 | 极小圆角矩形绘制异常、每帧临时 Font 未释放；电平快照持有外部可变数组 | 微小尺寸、绘制与快照隔离测试 |
| 日志与状态文件 | 音频线程日志经 UI 同步分发，日志无界增长；状态/设置写入可能被读到半文件 | 有界排队、轮转、原子替换与并发回归 |
| 可移植配置 | 内置某台机器的设备 ID 与 FFmpeg 路径；已保存设备失联可能误选其他接口 | 移除硬编码，显式配置、歧义和失联回归 |
| 低音滤波 | 长静音残留低于可听范围的 denormal，独立微基准明显变慢 | 极小滤波状态归零；原有频率响应/编解码幅度继续通过 |
| 时钟控制 | 输出已提交帧数与 padding 可跨写入读取，造成一帧量级的错误排队估算；首包标记缩短预热 | 一致快照、并发读写、长时漂移模拟、保留完整预热 |
| PCM 数学 | unity 快速路径漏过 NaN/Inf，极端浮点加法可溢出 | 有限值、极端值、声道隔离回归 |
| AC3 载体 | 引擎与编码器验证重复且不一致，截短长度可能被接受 | 共用验证，检查载体类型/标记/AC3头/48k帧长/填充 |
| 生命周期 | 重复或并发 Start/Stop/Dispose、早 EOF 与读取线程完成判定不完整 | 假管道子进程、并发启停、阻塞回调与真实 FFmpeg 退出测试 |
| 诊断 | 只有历史最大间隔，难与实听时刻关联；模式切换时均值读取有除零竞态 | 增加长间隙时间/次数、GC与时钟差指标，单次读取计数避免非有限均值 |

路由快照解析禁用 DTD，异常记录保留以便人工恢复；只恢复仍属于助手的默认角色。退出时未完成的资源清理继续保留所有权，不能把清理超时当作成功释放。

## 测试与部署证据

仓库提供可复跑的 `tests/run_tests.py`。它编译 C# fixture、使用实际 FFmpeg 编码/解码测试信号，并对待发布 EXE 做反射托盘/载体检查。新测试不调用生产入口、音频 Start、默认路由 setter 或登录任务 setter。

最终候选在 Windows 11 x64 build 26300 上通过 12 组回归；新增音频 6 类场景（本轮 51,520 次断言）、新增 UI 14/14、生产 EXE 托盘恢复 8/8、生命周期 20/20，六路编解码分离、低音幅度和静音阈值均通过。公开摘要见 [VALIDATION-3.3.0.json](VALIDATION-3.3.0.json)。

本机已通过真实注册登录任务的 Run 操作启动 v3.3.0，确认六路入口、编码与输出计数增长，并统一桌面与任务入口。真实标题栏关闭进入托盘后，同一进程/窗口句柄再次显示并保持打开，之后收回托盘继续运行。音量、FPS 与低音偏好保持。用户暂不方便试听，本轮不声称卡顿已经消除；任务 Run 也不等于已经重启验证。

测试产物中可能含机器路径或设备清单，因此原始运行日志不进入公开仓库。
